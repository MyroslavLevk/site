01 — The system

One module.
Two skies.

Night

StarNav

Uses the night sky to compute absolute heading. No error accumulation.

Day

SolarNav

Uses the sun to compute absolute heading, with continuous correction through daylight hours.

FNAV module

When the sky is temporarily unavailable, VIO and map-matching run alongside as a fallback for precise short-term positioning.
